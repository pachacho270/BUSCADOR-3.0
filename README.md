# BUSCADOR 3.0

Bot de Telegram para buscar películas, series y anime.

## Dependencias

Instalar con: `python -m pip install -r requirements.txt`

## Configuración

Necesita las variables BOT_TOKEN, TG_API_ID, TG_API_HASH y TMDB_READ_TOKEN. Configúralas en Termux y no publiques tus credenciales.

## Inicio

Ejecuta `python buscador.py` desde esta carpeta.

## Archivos privados

No subas la sesión de Telegram ni las bases de datos a GitHub.

## Respaldo

El código se conserva en el repositorio privado de GitHub.
